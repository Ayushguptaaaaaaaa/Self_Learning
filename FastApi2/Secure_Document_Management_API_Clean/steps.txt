TEST:
  Run in Python:

    hashed = hash_password("test123")

WHAT YOU LEARN:

STEP 6: JWT TOKEN GENERATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  □ app/core/security.py (add functions)
  □ app/schemas/auth.py (add schemas)

TASKS:
  6.1 Update app/core/security.py:
      - Import jose (JWT library)
      - Write create_access_token(user_id) function:
          * Create payload: {"sub": user_id, "exp": expiry_time}
          * Encode with JWT_SECRET_KEY
          * Return token string

      - Write decode_access_token(token) function:
          * Decode token
          * Return user_id
          * Handle expired/invalid tokens

  6.2 Update app/schemas/auth.py:
      - Add UserLogin schema (email, password)
      - Add Token schema (access_token, token_type)

TEST:
  Run in Python:
    from app.core.security import create_access_token, decode_access_token
    token = create_access_token(user_id=1)
    print(token)  # Long string with dots
    user_id = decode_access_token(token)
    print(user_id)  # Should be 1

WHAT YOU LEARN:
  → JWT tokens = temporary "pass" to access protected routes
  → Token contains user_id (encrypted)
  → Token expires after 15 minutes
  → Token is signed with secret key (can't be faked)
