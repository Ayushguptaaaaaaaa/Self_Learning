# Multi-Service API Aggregator Dashboard

## Project Overview
A FastAPI backend with a frontend dashboard that aggregates data from multiple external APIs:
- Weather (OpenWeatherMap)
- Cryptocurrency prices (CoinGecko)
- News headlines (NewsAPI)

## Project Structure
```
Multi_Service_API_Aggregator_Dashboard/
├── app/
│   ├── __init__.py
│   ├── main.py              # FastAPI app with all endpoints
│   ├── config.py            # Settings with API keys
│   ├── schemas.py           # Pydantic models
│   ├── api/
│   │   ├── __init__.py
│   │   └── routes.py        # (empty, routes in main.py)
│   └── static/
│       ├── index.html       # Frontend dashboard
│       ├── style.css        # Styling
│       └── app.js           # API calls and UI logic
├── .env                     # API keys (not in git)
├── requirements.txt
└── steps.txt               # This file
```

## How to Run

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Set Environment Variables
Create `.env` file with your API keys:
```
OPENWEATHER_API_KEY=your_key_here
NEWS_API_KEY=your_key_here
```

### 3. Start the Server
```bash
uvicorn app.main:app --reload
```

### 4. Access the Dashboard
- API Docs: http://localhost:8000/docs
- Dashboard: http://localhost:8000/static/index.html

## API Endpoints

### Weather
```
GET /weather/{city}
Example: /weather/London
```

### Cryptocurrency
```
GET /crypto?coins=bitcoin,ethereum,dogecoin
```

### News
```
GET /news?category=technology&country=us
Categories: general, business, technology, science, health, sports
```
